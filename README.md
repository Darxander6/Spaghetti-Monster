# Spaghetti-Monster
This little game where you make a spaghetti monster dance and move,
moving the cursor will make it dance,
to run:run the .exe file in the dist folder,
Controls:
  up arrow:moves the monster up
  down arrow:moves the monster down
  right arrow:moves the monster right
  left arrow:moves the monster left
  left click:the monster becomes bigger
  right click:the monster becomes smaller
